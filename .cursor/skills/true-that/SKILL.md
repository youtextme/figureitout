# True That

Deeming is a measurement, not a mood. The meter is a designed
disconfirmation *D* on atom *A*: if *A* were false, *D* would return a
killing observation.

Follow [RUN_FOREST.md](RUN_FOREST.md) in this folder. Closed tenets:
atoms, probe, conservation. Citation is not already-proven. Preference
is not a fact. Blocked means change the probe. You do not get to decide
there is no truth.
