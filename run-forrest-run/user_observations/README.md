# user_observations

Abstracted notes about **how** operators work. Never who they are.

Agents read these to find foundational platform capabilities.

Humans may read them too. If a note still looks personal, it is a bug —
strip it and re-file.

Each file is a day of JSONL plus a markdown twin under
`~/.run-forrest-run/observations/` on the operator's machine.

Public copies land here only when they are already abstracted and the
operator opted in.
